Application 03 · Data centres

Cyber Resilient Distributed AI Cloud

Instead of one large data centre, the Ionique design links a large number of small GPU sites: in offices, campuses, studios and edge locations. Each site is a standard building block; together they behave as a single AI cloud.

1 GPUA single card in an office or studio
8–64 GPUsA rack in a campus or edge site
Up to 1,000 GPUsA mini data centre
Resilient

No single point of failure

Workloads move between sites. If one site is lost, the cloud carries on from the others.

Cyber secure

Security built in

Each workload is isolated, and every site is built to the same secure reference design, with access control and monitoring from day one.

Distributed

Close to the user

Compute sits near the people and data it serves, for lower latency and so data can stay where it belongs.

What Ionique designs and builds

  • Site-node reference design, from a single GPU to a 1,000-GPU mini data centre
  • The operator software that joins sites into one cloud
  • Workload isolation and security
  • A standard, OpenAI-compatible interface for AI workloads
  • Interface specifications, acceptance testing and documentation

Who it is for

  • Organisations that want AI capacity on their own premises
  • Partners who host and operate GPU sites
  • Media, 3D and engineering teams with GPU-heavy work
  • Projects that need data kept within a site or a country
